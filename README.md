# 1C Extension Analyzer (Анализ расширений 1С)

Внешняя обработка для анализа расширений конфигурации (CFE) в **1С:Предприятие 8.3**: автоматический поиск коллизий, конфликтов заимствованных объектов и пересечений методов.

## Возможности

* **Поиск коллизий**: выявление конфликтов методов (`&Вместо`, `&ИзменениеИКонтроль`, `&Перед`, `&После`), форм, реквизитов и прав.
* **Фоновая выгрузка XML**: автоматическая выгрузка исходников через Конфигуратор без зависания интерфейса (или выбор готового каталога).
* **Удобный UI**: дерево объектов с фильтром «Только конфликты», цветовая индикация критичности и панель с рекомендациями.
* **Отчёт**: формирование табличного документа с возможностью печати и сохранения.

## Требования

* 1С:Предприятие 8.3.14+ (управляемое приложение, Windows).

## Запуск

1. Скачайте файл **`АнализРасширений.epf`** со страницы [Releases](https://github.com/volodimirmoskvitin/1c-extension-analyzer/releases).
2. Откройте в 1С (`Файл` -> `Открыть...`).
3. Нажмите **«Выполнить анализ»**.
